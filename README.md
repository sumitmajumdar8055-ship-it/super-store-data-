# super-store-data-📊 Superstore Sales & Profit Analytics Dashboard

This project presents an interactive Power BI dashboard built using the Superstore dataset to analyze sales performance, profit trends, customer behavior, product performance, and regional distribution. The dashboard provides business insights through dynamic visualizations, helping stakeholders make data-driven decisions.

🚀 Project Objectives
Analyze overall sales and profit performance.
Track order volume and business growth trends.
Identify top-performing products and customers.
Compare sales across categories and regions.
Visualize geographical sales distribution.
Enable interactive filtering using slicers.

📊 Key Insights
Technology category generated the highest sales and profit.
West region recorded the strongest sales performance.
A small group of customers contributed significantly to overall revenue.
Certain products consistently outperformed others in sales volume.
Interactive filtering allows deeper analysis by year, region, and category.
